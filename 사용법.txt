Slime Assistant — 보이는 슬라임 따라가기 (1인칭 기본·권장 / Roblox Above 시제품)

실행
  압축을 모두 풀고 SlimeAssistant 폴더의 SlimeAssistant.exe를 실행하세요.
  Python 설치는 필요 없습니다. Windows 10/11 64비트용입니다.

처음 설정
  1. 사용할 Roblox 계정을 직접 실행하고 같은 게임에 입장합니다.
     각 창은 최소화하지 마세요. 가능하면 같은 크기와 카메라 배율을 사용하세요.
     프로그램이 계정 로그인이나 Roblox 다중 실행 자체를 제공하지는 않습니다.
  2. 창 새로고침을 누르고 사용할 창을 체크합니다. PID로 구분할 수 있습니다.
     창 이름을 직접 붙여 어느 계정인지 구분하세요. 창 선택은 재실행마다 확인합니다.
     [작은 창 자동 배치]를 누르면 선택한 게임 창을 주 모니터에 바둑판으로 배치합니다.
     게임이 최소 창 크기를 강제해 겹치면 계정 수를 줄이거나 직접 배치하세요.
     배치 자체는 게임 조작을 시작하지 않습니다.
  3. 슬라임이 잘 보이는 창을 목록에서 선택하고 [선택 창 촬영]을 누릅니다.
     [슬라임 자르기]에서 슬라임 몸 전체를 드래그해 잘라 이름을 붙입니다.
     배경은 적게, 몸 윤곽과 눈 등 구별되는 부분은 포함하세요.
     잡을 슬라임의 색상·각도·근거리/중거리별로 몇 장 등록하세요.
     준비한 스크린샷은 [사진 열기]로 불러와 등록할 수도 있습니다.
  4. [현재 사진 인식 시험]으로 상자가 슬라임에 맞게 생기는지 확인합니다.
     화면 가장자리의 UI나 아이템 그림이 잡히면 탐색 영역을 줄이세요.
     오인식이 많으면 인식 기준을 올리세요. 안 잡히면 다른 모습을 추가하세요.
  5. 감지 전용으로 시작하면 각 작은 창을 앞으로 가져오지 않고 반복해서 읽습니다.
     계정별 인식 결과를 모아보기와 목록의 감시 상태에 표시합니다.
     [시작 시 도우미 최소화]는 기본으로 켜져 있습니다. 도우미가 게임을 가리지 않게
     하려는 설정입니다. 다른 모니터에 도우미를 두면 해제하고 모아보기를 볼 수 있습니다.
     도우미가 최소화돼 있어도 F9로 정지할 수 있습니다. 다시 열기는 작업 표시줄을 사용하세요.
  6. 각 계정에 검을 장착하고 메뉴·채팅·인벤토리를 닫은 뒤 사냥 모드를 선택합니다.
     [몹 추적·접근 W]와 [가림·일시 오류 자동 복구]는 이 버전에서 기본으로 켜져 있습니다.
     시작 시 모드는 항상 감지 전용입니다. 사냥은 사용자가 직접 선택해야 합니다.

이번 버전의 추적 동작
  게임 안에서 먼저 1인칭으로 맞추고, 프로그램의 카메라도 [1인칭 (권장)]으로 선택하세요.
  캐릭터 몸체가 표적을 가리지 않고 조준점 기준으로 제어하기 쉬워 우선 권장합니다.
  실제 게임의 1인칭 지원·카메라 입력은 미검증이며, 프로그램이 게임 시점을 자동 변경하지는 않습니다.
  3인칭을 쓴다면 게임 안의 시점과 함께 [3인칭 (우클릭 회전)]을 선택하세요.
  이전 버전 설정에 camera_mode가 없으면 1인칭 기본값으로 전환합니다.
  매번 보이는 후보 중 조준점 가까운 대상을 고릅니다. A를 죽을 때까지 고정하지는 않습니다.
  이동 후에도 확인 이력을 유지하지만, 새 화면의 표적 상실·다른 라벨·큰 위치 변화에는 재확인이 필요합니다.
  슬라임 연속 확인 → 카메라 방향 조정 → 중앙에 있고 멀면 W로 짧게 접근 →
  화면에서 설정한 크기 이상으로 가까워지면 마우스로 공격합니다.
  전진 후에는 화면을 새로 읽고 슬라임을 다시 확인합니다.
  표적을 잃으면 전진을 중단합니다. 탐색 옵션을 켠 경우 이후 회전하며 다시 찾습니다.
  가림 복구 시에는 창을 앞으로 가져온 후 현재 화면을 새로 읽습니다.
  가려진 상태의 오래된 좌표를 이용해 무작정 이동하거나 공격하지 않습니다.
  겹친 계정들도 창을 번갈아 앞으로 가져와 확인할 수 있지만, 계정 수가 늘면 조작이 느려집니다.
  길찾기·장애물 우회·사망 인식·자동 부활·서버 재접속·계정 로그인을 구현한 것은 아닙니다.

조작 방식과 설정
  F8: 시작/정지. 시작 버튼 후 2초 뒤 동작합니다. F9: 긴급 정지.
  자동 복구가 켜진 사냥 모드는 포커스가 바뀌어도 필요한 게임 창을 다시 가져옵니다.
  PC를 직접 사용하려면 먼저 F9로 정지하세요. F9 정지는 자동으로 재개하지 않습니다.
  자동 복구를 끈 사냥 모드는 다른 창으로 포커스가 바뀌면 전체 정지합니다.
  감지 전용은 포커스가 바뀌어도 감시를 계속합니다.
  감시 간격: 전체 계정을 한 번씩 읽는 최소 주기, 기본 0.25초입니다.
     계정 수·기준 이미지 수·PC 성능에 따라 실제 한 순회는 더 오래 걸릴 수 있습니다.
  일치 기준: 기본 0.84. 신뢰 확률이 아니라 이미지 유사도 기준입니다.
  공격 거리: 감지된 몸 높이/화면 높이 비율. 기본 0.16 이상에서 공격합니다.
     게임의 실제 사거리를 측정하는 값이 아닙니다. 게임에서 직접 조정해야 합니다.
  카메라 감도: 시점 이동 크기. 반대로 돌거나 튀면 정지 후 조정하세요.
  공격 간격: 기본 0.65초. 선택한 창의 중앙에서 일반 마우스 공격을 합니다.
  카메라 설정: 1인칭은 우클릭 없이 시점을 조정하고, 3인칭은 우클릭을 함께 사용합니다.
  몹 추적·접근 W: 기본 켜짐. 짧은 전진 후 새 화면에서 다시 판단합니다.
  미감지 시 회전 탐색: 기본 꺼짐. 선택하면 표적이 없을 때 수평으로 탐색합니다.
     지형·낭떠러지·장애물·사망·회복·리스폰은 이해하지 못합니다.
  계정별로 표적이 3번 연속 확인되고 화면이 최근에 캡처된 경우에만 표적을 조작합니다.
  자동 회전 탐색을 켠 경우에는 표적이 없어도 해당 창을 활성화해 탐색할 수 있습니다.
  표시되는 공격 횟수는 클릭 전송 횟수이며 처치 수나 수익이 아닙니다.

다계정의 정확한 의미
  게임은 각 작은 창 안에서 실행해 두고, 프로그램은 창별로 화면을 반복해서 읽습니다.
  감지만 할 때는 창 활성화·클릭·키 입력을 하지 않습니다.
  사냥 모드는 조작 또는 가림 복구가 필요한 창을 차례로 활성화하고 화면을 새로 읽습니다.
  실제 마우스와 키보드를 사용하며 백그라운드 동시 입력을 제공하지 않습니다.
  계정 수가 늘어나면 감시·조작 주기도 길어집니다.
  창이 가려졌는지 탐색 영역의 25개 지점을 확인하고, 가림이 감지되면 그 계정은 보류합니다.
  지점 사이의 작은 가림을 모두 잡아내는 것은 아니므로 창끼리 겹치지 않게 배치하세요.
  감지 전용은 가린 계정의 감시를 보류합니다.
  자동 복구를 켠 사냥 모드는 가린 창을 앞으로 가져와 재확인합니다.
  다른 창이 항상 위에 있거나 게임 창이 화면 밖에 있으면 복구에 실패할 수 있습니다.
  최소화한 창, 화면 밖의 창, 렌더링을 멈춘 창을 정상 감시한다고 보장하지 않습니다.
  작은 창에서 실제 사용할 크기로 슬라임 기준을 등록하세요. 너무 작은 슬라임은 감지하기 어렵습니다.
  창 활성화·캡처·입력이 일시적으로 실패하면 자동 복구 옵션에 따라 해당 계정만
  1/2/4/8초 간격으로 재시도합니다. 다른 계정은 계속 처리합니다.
  닫히거나 최소화된 창은 대기합니다. 게임을 새로 실행해 PID가 바뀌면 F9 정지 후
  창 새로고침과 재선택이 필요합니다. 게임 실행·로그인은 자동 복구하지 않습니다.
  입력 버튼·키를 해제하지 못하는 오류나 예상하지 못한 오류는 전체를 정지할 수 있습니다.
  관리자 권한 차이, 입력 차단, 카메라 모드에 따라 작동하지 않을 수 있습니다.

현재 검증 범위와 한계
  합성 이미지 위치 인식, 배율 변화, 영역 제외, 추적 초기화,
  비활성 창 감시 시 활성화 없음, 계정별 공격 분리, 가린 창 제외,
  복구 해제 시 포커스 변경 정지, 긴급 키 정지, 키/버튼 해제, 배치 계산,
  가림 복구 후 재확인, 접근→공격 판단, 표적 상실 시 전진 중단,
  일시 캡처 오류 시 다른 계정 지속 처리를 자동 테스트했습니다.
  창·입력은 테스트에서 모의 처리했으며 실제 게임을 조작하지 않았습니다.
  실제 Above 플레이로 슬라임 인식·공격·장시간 다계정 사냥은 아직 검증하지 않았습니다.
  신경망 학습 모델이 아니라 등록한 이미지와 비슷한 모습을 찾는 방식입니다.
  등록하지 않은 모습, 가림, 조명 변화, 움직임, 카메라 회전에 취약할 수 있습니다.
  자동 사냥 완제품이나 완전 무인 운용을 보장하지 않습니다.

데이터
  기준 이미지·설정·로그: %LOCALAPPDATA%\SlimeAssistant
  이미지나 계정 정보는 서버로 보내지 않습니다. 비밀번호를 요구하지 않습니다.
  삭제한 기준 이미지는 archived-templates 폴더로 이동합니다.

소스로 실행/수정
  Python 3.13 64비트 기준:
    python -m venv .venv
    .venv\Scripts\python -m pip install -r requirements.txt
    .venv\Scripts\python run.py
  테스트:
    .venv\Scripts\python -m unittest discover -s tests -v
  실행 파일 빌드:
    powershell -ExecutionPolicy Bypass -File build.ps1
